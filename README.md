# 煤矿法规标准智能检索（防冲专题）

网站：https://mactavishyzm.github.io/coal-law-assistant/

## 2026-10-18 精准检索升级

- 默认要求同一条文中的关键词全部命中，完整词组、术语关联和相邻出现的内容优先排序。文件标题仅在正文条件满足后辅助排序，不再凭标题或零散的相同字词返回整份文件。
- 对应力监测、微震监测、煤层卸压爆破、顶板深孔爆破等保留术语约束，减少不同监测对象、不同卸压措施之间的误匹配。
- 专题标准的小节省略完整术语时，可结合本标准主题判断，正文仍须包含全部关键词；结果会标明使用了文件主题。选择“完整词组”可只保留原文中连续出现的词组。
- 多关键词可用空格分隔，例如`卸压钻孔 间距`、`应力监测 传感器`；双引号或“完整词组”模式可锁定连续词组。
- 支持限定类别和文件；输入`KA 38-2026 4.4`可直接定位标准条款，`2026防冲细则 第47条`可直接定位法规条文。中文和阿拉伯数字条款号可互用。
- “扩展术语”须主动选择，仅补充“大直径/大孔径”“水压致裂/水力压裂”两组近似术语，结果标明实际命中的写法；其他关键词仍须全部满足。引用内容仍需结合原文判断适用性。
- 结果显示命中关键词和匹配方式，不把内部排序分数当作可信度。同一条款的跨页内容合并展示，保留每页原文和全部公式图。

运行`node tests/search-precision.cjs`可检查实际条文查询、标准号与条款号、跨页合并、数值单位及误匹配案例。这些样例用于回归检查，不代表对全部查询的准确率评估。

## 文件

`index.html`包含离线检索数据；`index-data.json`是相同数据的独立副本。`assets/search-engine.js`提供本地检索，`assets/corrected-app.js`与`assets/corrected-text.css`提供界面；`formulae/`保存原文公式图，`pages/`保存583页原文图，`source/`保存24份PDF。

本地使用时保留完整目录，可在目录内运行`python -m http.server 8080`。修改后可通过附带的PowerShell脚本更新原GitHub仓库。
