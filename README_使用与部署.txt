煤矿法规标准智能检索（防冲专题）——2026-10-08高清新版

一、内容
· 24份不重复PDF：2025版《煤矿安全规程》、2026版《防治煤矿冲击地压细则》、2026版《煤矿重大事故隐患判定标准》、《陕西省煤矿冲击地压防治规定（试行）》、GB/T 25217第1～14部分、KA 35～40-2026。
· 583个PDF实际页面，已生成对应WebP高清页面图像（pages目录）。
· 2078条检索单元、模糊检索、类别过滤、原文页内嵌截图、前后页翻阅、隐患描述辅助匹配。
· 规程与地方规定从有文字层的PDF提取；国标/行标及扫描件以中文OCR仅构建辅助索引。索引可能有错别字或数值错误，法律依据必须以页面截图为准。

二、本地打开
把整个ZIP解压到同一个文件夹，不要单独移动index.html或pages目录。
Windows电脑上双击index.html即可检索。如果浏览器限制访问本地文件，请在解压目录运行：python -m http.server 8080，浏览器打开 http://127.0.0.1:8080。

三、更新原有GitHub网站
本包包含“部署到GitHub.ps1”。运行前请安装 Git for Windows，并确认已在此电脑登录GitHub且有仓库写入权限。
在PowerShell中切换到解压目录，运行：powershell -ExecutionPolicy Bypass -File .\部署到GitHub.ps1
脚本会克隆 MactavishYZM/coal-law-assistant，覆盖旧的 index.html、source、pages、图标等；移除会覆盖新首页的旧build-pwa工作流；然后提交并推送main分支。原文件保留在Git提交历史中。
注意：上传至公开GitHub Pages前，请确认所含国标和行业标准PDF具备公开发布授权。

四、重要说明
· 原文截图来自这次上传的PDF本身，检索页面与PDF物理页码一一对应。
· 有些扫描标准原PDF的文字编码不正确。此版对这些文档另行OCR建立索引，但不以OCR文本取代法规原文。
· 通过浏览器在线安装为PWA后，浏览过的截图会按需缓存；首次离线查看全部583页前，必须保证所需页面已加载。完整本地资料包无需网络访问。
